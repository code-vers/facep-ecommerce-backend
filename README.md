# Face-Commerce Backend API

This is the backend service for Face-Commerce.
Built with Node.js, Express, TypeScript, PostgreSQL, and Prisma.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Generate Prisma Client:
```bash
npm run prisma:generate
```

3. Setup environment variables (create a `.env` file from `.env.example`).

4. Run the development server:
```bash
npm run dev
```

## API Documentation
Once running, swagger docs are available at `/api/docs`.
